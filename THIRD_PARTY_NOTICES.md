# Third-party code

Echo-Forcing builds on code from [Self-Forcing](https://github.com/guandeh17/Self-Forcing) and includes adapted [Wan2.1](https://github.com/Wan-Video/Wan2.1) components under `wan/`. Both upstream repositories provide their code under the Apache License 2.0 license. The Apache license text is included in [`licenses/Apache-2.0.txt`](licenses/Apache-2.0.txt).

The Wan components in this repository have been modified for scene-memory inference and the associated attention and cache paths. Upstream copyright notices in source files are retained. The root [`LICENSE`](LICENSE) covers Echo-Forcing's original contributions; the upstream licenses continue to apply to their respective code.
